# C# Customer Data App

A C# Windows Forms application that retrieves and displays customer information from a SQL Server Northwind database using a data access layer.

## Live Web Demo

[View the deployed Customer Data App](https://magenta-moonbeam-c014de.netlify.app/)

The live browser version recreates the main features of the original desktop application so the project can be tested without installing Visual Studio or connecting to a local SQL Server database.

## Project Features

- Displays the total number of customer records
- Lists customer company names
- Displays customer contact last names
- Searches and filters customer results
- Organizes customer data in an easy-to-read interface
- Uses sample Northwind-style records in the web version
